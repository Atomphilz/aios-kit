# Begriffe, zwei Zeilen je Wort

Zum Nachschlagen oder Ausdrucken. Das AIOS verweist hierher, statt ein Wort zum
dritten Mal zu erklären. Fehlt ein Wort, sag es, dann kommt es dazu.

**Prompt.** Das, was du dem Assistenten schreibst. Eine Frage, eine Bitte,
eine Anweisung; mehr ist es nicht.

**Chat.** Das Gespräch mit dem Assistenten, von oben nach unten lesbar. Ein
neuer Chat fängt ohne Erinnerung an das vorige an; die Dateien bleiben.

**Browser.** Das Programm, mit dem du Webseiten öffnest: Chrome, Firefox,
Safari, Edge, Brave.

**Cloud.** Speicher auf fremden Rechnern im Internet, zum Beispiel Google
Drive oder iCloud. Das AIOS liegt nicht dort, sondern auf deinem Rechner.

**Download.** Eine Datei aus dem Internet auf deinen Rechner holen. Sie landet
im Ordner „Downloads“, wenn du nichts anderes wählst.

**Datei und Ordner.** Eine Datei ist ein Dokument, ein Ordner ein Behälter für
Dateien und weitere Ordner. Das AIOS ist ein Ordner mit vielen Textdateien.

**Pfad.** Der Weg zu einer Datei durch die Ordner, mit Schrägstrichen:
`aiOS/daily/2026-11-04.md` heißt: Ordner aiOS, darin daily, darin die Datei.

**Markdown.** Einfacher Text mit ein paar Zeichen für Überschriften (`#`)
und Listen (`-`). Jedes Textprogramm kann ihn öffnen.

**Terminal.** Das schwarze Fenster, in das man Befehle tippt. In VS Code
heißt es unten „Terminal“. Du brauchst es nur beim Installieren.

**VS Code.** Das Programm, in dem du den aiOS-Ordner öffnest. Links die
Dateien, rechts der Chat mit dem Assistenten.

**Claude Code.** Der Assistent selbst, als Erweiterung in VS Code. Er liest
und schreibt die Dateien in deinem Ordner.

**Skill.** Ein fester Ablauf, den du mit Schrägstrich startest, zum Beispiel
`/day-open`. Dahinter steckt eine Textdatei mit Anweisungen.

**Token.** Die Einheit, in der der Assistent Text zählt, ungefähr ein
Silbenstück. Wichtig nur, weil ein langes Gespräch irgendwann voll ist.

**Commit.** Ein gespeicherter Stand aller Dateien mit Datum und Notiz, wie
ein Foto des Ordners. Braucht man, wenn man mit Git arbeitet; am Anfang nicht.

**Repository.** Ein Ordner, dessen Stände Git aufhebt, oft kurz „Repo“. Das
Kit kommt aus einem Repository auf GitHub; dein Ordner muss keins sein.
